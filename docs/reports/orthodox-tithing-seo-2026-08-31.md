# Orthodox tithing and parish software SEO

## Positioning

AGAPAY is the Orthodox tithing app and custom-built Orthodox church management software platform. The homepage targets tithing and the connected platform; `/give` targets the complete Orthodox church management software product. The approved hero H1s, typography, section order, pricing, calculator, and restored content remain intact.

Updated the homepage, Give, About, and demo page titles, descriptions, and social metadata. Visible hero descriptions, product headings, About copy, and three Give FAQs explain this positioning. Custom-built means designed for Orthodox parish workflows, not a promise of bespoke development per parish. Existing feature and pricing qualifications remain.

## Technical changes

- Home and Give now reference the same SoftwareApplication entity at `https://agapay.app/give#software`, with consistent features and published prices. Added the homepage WebPage entity and its mainEntity relationship.
- Removed generic search phrases masquerading as alternate site names. The site name remains AGAPAY; software alternate names are the actual AGAPAY Give and My AGAPAY names.
- Corrected the homepage's obsolete free-software claim. Free registration does not mean the paid parish platform is free.
- Synchronized every structured FAQ with the visible question and answer, including the new tithing and Orthodox workflow explanations. No reviews, ratings, or unsupported claims added.
- Give uses the existing 1200 by 630 social share image with matching dimensions. Canonical URLs remain clean and exclude campaign parameters.
- Updated sitemap lastmod only for the four pages edited in this release. Existing crawl access and redirect rules remain unchanged; no new JavaScript or runtime dependencies.

## Validation and follow-up

Run the existing platform, Give consolidation, security FAQ, and quality checks. Consolidation checks now guard shared software identity, paid pricing, and exact visible/structured FAQ parity. Check rendered headings and layout, served HTML, canonical tags, robots headers, JSON-LD, sitemap, and social image dimensions before and after release.

Google chooses search titles and snippets and can take days or weeks to recrawl. These changes improve the site's signals but do not guarantee ranking or particular search-result wording. No authenticated Search Console connector is available in this task, so indexing submission and search-performance data are not claimed. The property owner can request indexing for `/` and `/give` and submit `https://agapay.app/sitemap.xml` in Search Console. FAQ markup is not a promise of FAQ rich results.
